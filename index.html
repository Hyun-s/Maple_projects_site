02 / Working principles

Evidence
before claims

The pages favor inspectable records over live demos that hide assumptions or private infrastructure.

  1. 01

    State the evidence

    Metrics and system claims carry a snapshot date, data scope, and validation status.

  2. 02

    Show the boundary

    Public architecture stays separate from private credentials, runtime endpoints, and source corpora.

  3. 03

    Keep failures visible

    Observed failures become documented causes, system changes, regression checks, and remaining risks.

  4. 04

    Prefer static records

    Core technical context remains fast, inspectable, and useful without a live backend.
