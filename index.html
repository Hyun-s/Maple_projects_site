02 / Working principles

보여주기보다
증명하기

화려한 데모 대신 다시 확인할 수 있는 구조와 명시적인 경계를 남깁니다.

  1. 01

    Evidence first

    수치와 주장은 snapshot 날짜, 데이터 범위, 검증 상태와 함께 기록합니다.

  2. 02

    Boundaries visible

    공개 가능한 설계와 비공개 runtime·credential·corpus의 경계를 화면에 드러냅니다.

  3. 03

    Failures included

    실패를 숨기지 않고 원인, 해결, 회귀 테스트와 남은 위험으로 변환합니다.

  4. 04

    Static by default

    라이브 endpoint 없이도 핵심 내용이 빠르고 안전하게 전달되는 정적 페이지를 우선합니다.
