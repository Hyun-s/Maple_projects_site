A static, reproducible record of translating in-game avatars into anime illustrations and realistic portraits—while keeping model weights, inference endpoints, and private data offline.

01 / Overview

What are we trying to preserve?

Better stylization is not useful if the generated portrait no longer reads as the same character. This experiment treats visual quality and character identity as separate, equally visible objectives.

RQ 01

Translation quality

Which model–method pair produces the most coherent anime and realistic images?

RQ 02

Identity preservation

How well are hairstyle, palette, outfit, accessories, and overall silhouette retained?

RQ 03

Adaptation efficiency

Do lightweight adaptation methods improve the trade-off over a zero-shot baseline?

Publication boundary

This site contains only approved text, aggregate metrics, and selected samples. It does not expose model artifacts, credentials, dataset archives, or API addresses.

Embedding similarity between the input character and generated image.

LPIPS ↓

Perceptual feature distance between input and generated image.

Composite score definition

Quality = 0.5 × Aestheticnorm + 0.3 × exp(−FID / 100) + 0.2 × ISnorm

Identity = 0.6 × CLIPnorm + 0.4 × (1 − LPIPSclamped)

Overall = harmonic mean(Quality, Identity)

Aesthetic and IS are normalized against 10. CLIP [−1, 1] is mapped to [0, 1]. FID and IS are unstable on very small sample sets, so smoke-test runs are not published as benchmark evidence.
