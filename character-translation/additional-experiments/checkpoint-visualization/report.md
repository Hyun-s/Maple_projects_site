# FLUX checkpoint-by-checkpoint visual audit

This is a visual-only comparison. No aggregate evaluation metric is reported.

- Checkpoints: 30 (3,000 through 90,000)
- Fixed combinations per checkpoint: 4
- Exact training-caption prompt: `a maplestory character wearing {tokens}`
- Anime-style prompt: `an anime-style character wearing {tokens}`
- Each checkpoint uses the same combinations, seeds, CFG, and inference steps for both prompts.
